# Django Todo List Application

A functional and stylish task management web application built with Python and Django. This project allows users to organize their daily tasks, categorize them with tags, and set deadlines using an interactive calendar.

## 🚀 Features

- **Task Management**: Create, update, delete, and track the status of your tasks.
- **Tagging System**: Categorize tasks using a many-to-many relationship with customizable tags.
- **Dynamic Date Picker**: Integrated [Flatpickr](https://flatpickr.js.org/) for a user-friendly deadline selection.
- **Responsive UI**: Styled with **Bootstrap 5** and **Django Crispy Forms** for a modern, mobile-friendly experience.
- **Completion Toggle**: Quickly switch task status between "Done" and "Undo" directly from the dashboard.

## 🛠️ Tech Stack

- **Backend**: Python 3.12, Django 6.0
- **Frontend**: HTML5, Bootstrap 5, JavaScript
- **Forms**: Django Crispy Forms (Bootstrap 5 template pack)
- **Database**: SQLite (Development) / PostgreSQL (Production ready)
